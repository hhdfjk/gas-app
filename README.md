# تطبيق توصيل قناني الغاز — قضاء الميمونة
## الحالة: المشروع مكتمل بجميع الوحدات (عميل + سائق + إدارة) ✅

بُني كتطبيق ويب تقدمي (PWA) بـ React + Firebase، قابل للتحويل إلى APK حقيقي ونشره على Google Play.
كل خطوات الإعداد تعمل من متصفح الهاتف بدون أي حاسوب.

---

## محتويات المشروع

| المجلد/الملف | الوظيفة |
|---|---|
| `src/pages/customer/` | كل شاشات العميل: ترحيب، دخول OTP، الرئيسية، الطلب، التتبع، المحادثة، العناوين، الحساب |
| `src/pages/driver/` | دخول السائق، قائمة طلباته، تفاصيل الطلب مع التتبع الحي وتغيير الحالة |
| `src/pages/admin/` | لوحة الإدارة: الطلبات، السائقون، العملاء، المنتجات، التقارير |
| `src/contexts/AuthContext.jsx` | تسجيل الدخول الحقيقي برقم الهاتف + OTP، وتحديد الدور (عميل/سائق/مدير) |
| `firestore.rules` | نظام الصلاحيات الحقيقي (كل طرف يرى بياناته فقط) |
| `functions/` | إشعارات Push حقيقية تُرسَل تلقائيًا عند: طلب جديد، تغيير حالة، تعيين سائق، رسالة جديدة |
| `docs/database-schema.md` | توثيق قاعدة البيانات الكاملة |

## خطوات التشغيل (من الهاتف بالكامل)

### الخطوة 1 — مشروع Firebase
أنشئ مشروع Firebase من console.firebase.google.com، وفعّل:
- **Authentication**: فعّل "Phone" (للعميل والسائق)، وفعّل "Email/Password" (لحساب المدير فقط).
- **Firestore Database** (وضع الإنتاج).
- **Cloud Messaging**.
- **Hosting**.

انسخ إعدادات تطبيق الويب (apiKey...) والصقها في **مكانين**:
1. `src/firebase/config.js`
2. `public/firebase-messaging-sw.js`

### الخطوة 2 — رفع قواعد الأمان
Firestore Database → Rules → الصق محتوى `firestore.rules` بالكامل → Publish.

### الخطوة 3 — بيانات أولية في قاعدة البيانات
من Firestore Console أضف يدويًا:
- مجموعة `products`: مستندين (القنينة الاقتصادية 6000، القنينة الثانية 9000) كما في `docs/database-schema.md`.
- مجموعة `settings` → مستند باسم `app` بالحقول الموضحة في الشيما.

### الخطوة 4 — إنشاء حساب المدير
1. Authentication → Users → Add user → أدخل بريدًا إلكترونيًا وكلمة مرور لحسابك كمدير.
2. انسخ الـ **UID** الذي يظهر لهذا المستخدم.
3. أنشئ يدويًا مستندًا في مجموعة `admins` بنفس هذا الـ UID، بالحقلين: `name`, `role: "super_admin"`.
4. سجّل الدخول لاحقًا من شاشة `/admin/login` بنفس البريد وكلمة المرور.

### الخطوة 5 — رفع المشروع على StackBlitz للتعديل والتشغيل من الهاتف
1. افتح stackblitz.com من متصفح الهاتف وسجّل الدخول.
2. أنشئ مشروع React (Vite) جديد.
3. انسخ كل محتويات هذا المشروع إليه بنفس أسماء المجلدات والملفات.
4. سيعمل التطبيق مباشرة داخل معاينة StackBlitz — يمكنك تجربة تسجيل الدخول والطلب والتتبع فورًا.

### الخطوة 6 — تفعيل Cloud Functions (للإشعارات الحقيقية)
Cloud Functions تحتاج ترقية مشروع Firebase لخطة **Blaze** (لا تزال فيها حصة مجانية كبيرة شهريًا، ولن تُحاسَب إلا عند تجاوزها).
من Firebase Console → Upgrade → اختر Blaze (تحتاج ربط بطاقة، لكن الاستخدام العادي لتطبيق صغير يبقى ضمن المجاني).
ثم انشر مجلد `functions/` عبر Firebase Console مباشرة أو أخبرني وسأشرح لك طريقة بديلة إن لم ترغب بترقية الخطة الآن.

> ملاحظة: التطبيق يعمل بالكامل حتى بدون هذه الخطوة (الطلبات، الدخول، التتبع، المحادثة)، فقط إشعارات الـ Push الفعلية (التي تصل حتى والتطبيق مغلق) تحتاج هذه الخطوة.

### الخطوة 7 — تفعيل مفتاح VAPID للإشعارات
Firebase Console → Project Settings → Cloud Messaging → Web configuration → "Generate key pair".
انسخ المفتاح والصقه في `src/contexts/AuthContext.jsx` مكان `PASTE_VAPID_KEY_HERE`.

### الخطوة 8 — تحويل التطبيق إلى APK حقيقي ونشره
1. انشر المشروع عبر Firebase Hosting (StackBlitz فيه زر نشر مباشر، أو Firebase Console → Hosting → اتبع التعليمات).
2. بعد الحصول على رابط الموقع (مثال: `https://gas-maimouna.web.app`)، افتح **pwabuilder.com** من متصفح الهاتف.
3. الصق رابط موقعك → سيحلله تلقائيًا → اختر "Android" → حمّل ملف الـ APK/AAB جاهزًا.
4. ارفع ملف AAB إلى Google Play Console لنشره على المتجر (يتطلب حساب مطوّر Google بمبلغ اشتراك رمزي لمرة واحدة).

## كيف تضيف سائقًا جديدًا (تدفق عملي)
1. اطلب من السائق فتح التطبيق → "دخول السائق" → إدخال رقمه → تأكيد OTP (تمامًا كالعميل).
2. بعد أول دخول له، اذهب إلى Firebase Console → Authentication وابحث عن رقمه، انسخ الـ UID.
3. من لوحة الإدارة (تبويب السائقون) اضغط "+ إضافة سائق" والصق UID مع اسمه ورقمه.
4. من هذه اللحظة يستطيع السائق رؤية الطلبات المسندة إليه.

---

## اختبار سريع لتدفق الطلب الكامل
1. سجّل دخول كعميل → أضف عنوانًا → اطلب قنينة.
2. من لوحة الإدارة: اقبل الطلب → ابدأ التجهيز → عيّن السائق.
3. سجّل دخول كسائق (من متصفح آخر أو نافذة تصفح خفي) → ستظهر له نفس الطلب → اضغط "بدء التوصيل".
4. راقب من حساب العميل كيف تتحدث حالة الطلب لحظيًا إلى "السائق في الطريق".
5. جرّب المحادثة بين الطرفين من زر "💬 مراسلة".

## نقاط قابلة للتوسع لاحقًا (كما طلبت)
البنية الحالية تسمح بإضافة كل التالي دون إعادة هيكلة: مناطق توصيل متعددة (حقل `regions` في settings)، كوبونات وعروض (مجموعة جديدة `coupons`)، تقييم السائق (حقل `rating` بعد التسليم)، دفع إلكتروني (حقل `paymentMethod` جاهز في الطلب)، أوقات عمل (`workingHours` موجود في settings).

أخبرني بأي خطوة تتعثر بها بالتفصيل (ولقطة شاشة إن أمكن) وسأشرحها لك، أو أخبرني إن أردت البدء بشرح إضافة الكوبونات أو أي ميزة توسّع أخرى.
